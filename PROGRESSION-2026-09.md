# September progression and polish validation

Production-code policy benchmark: `node scripts/reward-sim.cjs` and `node scripts/reward-sim.cjs --reserve-decor`. Each command runs 180 seeded, three-hour simulations: 30 seeds, fresh/mid/advanced fixtures, saving/shopping policies. These are not human playtime or retention measurements. Trial victory at five minutes is assumed, not solved; all other actions use production functions. UI actions take no simulated time. Offline breaks and cosmetic spending are not included.

## Results (median simulated minutes)

| Fixture / policy | Elder, savings off | Elder, savings on | All decor runs off → on |
| --- | ---: | ---: | --- |
| Fresh / save | 94.3 | 94.3 | 30 → 30 |
| Fresh / shop | 58.1 | 66.3 | 0 → 30 |
| Mid / save | 77.1 | 77.1 | 30 → 30 |
| Mid / shop | 42.8 | 54.3 | 0 → 30 |
| Advanced / save | 46.8 | 46.8 | already owned |
| Advanced / shop | 12.5 | 12.5 | already owned |

Every run reached a board Elder. Savings-on shoppers completed all decor at medians 52.9m fresh and 42.3m mid. Saving advanced players retained a median 427,610 coins at three hours. This supports optional cosmetic coin sinks, not higher mandatory prices or confiscation of existing savings.

Upgrade savings is opt-in and persists. It reserves the first affordable-by-discovery, unowned decor item's full price from dragon purchases only. It does not buy anything automatically or prevent land/decor/cosmetic spending. Existing prices, regen, rewards and daily limits remain unchanged.

## Board polish

Selection outline, dashed matching-stage hints, counts toward five, final-Elder explanation, open-tile count and full-board advice. Explicit lock/open price labels and accessible tile descriptions. Corrected stack consolidation losing a shiny target and prevented Elders advertising valid merge targets. Fixed action dock remains unchanged.

## Limits

Long-term retention still needs human playtesting. Finite cosmetic rewards extend the collection goal but cannot provide infinite content. No claim of error-free software is made; regression tests and browser checks cover the changed paths.

## Endgame Collection

Find it under Nest → Collection. Sanctuary styles are decorative board outlines/glows and keeper-profile accents, not new rooms or income upgrades. They reuse the established interface art direction without altering dragon sprites. Titles equip on Home; frames equip through The Stash.

| Reward | Requirement | One-time cost |
| --- | --- | --- |
| Ember Garden / Moon Pool / Grove Canopy | Corresponding Main mastery claimed | Each: 25,000 coins + 2 tokens |
| Sanctuary Guardian title | All three Main masteries claimed | 100,000 coins |
| Steadfast Keeper title | Four completed weekly sets, not necessarily consecutive | 50,000 coins |
| Existing Obsidian frame, now earnable in contracts shop | All three Main masteries claimed | 75,000 coins + 4 tokens |

Existing Obsidian ownership is preserved. Completion history begins with this update; an already-completed current saved week is credited, but earlier unrecorded weeks cannot be reconstructed. Missing a week never removes progress or owned cosmetics. Each completed week is credited once, independently of the Monday reset. Unlocks cannot be bought twice or purchased during Trials. Equipping a collectible title replaces the active mastery title without deleting that title's unlock or the original keeper title.

Removed the development-only click-to-level-up binding from the level display. No other XP tuning was made.

Final verification: 67 game regression tests, 3 sprite tests, JavaScript syntax checks and diff whitespace checks. Desktop/light/dark fixtures and 320px live board/Collection checks; board action hit-testing, selection and scroll checks; no browser console errors observed. Static endgame fixtures are generated by `node scripts/preview-endgame.cjs` and do not read or write browser saves.
